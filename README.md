# Finanzy

Aplicativo Expo/React Native de controle financeiro local, com SQLite, preferências no aparelho, feriados da BrasilAPI, lembretes locais e exportação.

O projeto executável está em `Finanzy/`.

```powershell
cd Finanzy
npm install
npm run start
```

Validação:

```powershell
npm run lint
npm run typecheck
npm test
```

Consulte [a arquitetura](docs/ARCHITECTURE.md), [a implementação do backend local](docs/BACKEND_IMPLEMENTATION.md) e a [spec funcional](docs/SPEC_BACKEND.md).
